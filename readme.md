# Research on Multi-Robot Path Planning Based on Conflict in Order Fulfillment System (Matlab Code Implementation)

Research on Multi-Robot Path Planning Based on Conflict for Order Fulfillment Systems (Matlab Code Implementation)
Research on multi-robot path planning using mobile robots for order fulfillment systems, similar to Kiva.
With the development of automated logistics systems, mobile robots, as key tools in transportation systems, have seen rapid technological advancements. Multi-robot path planning is a highly challenging problem in the field of robot navigation research. Multi-robot path planning is a multi-objective optimization problem, how to achieve route coordination among robots, avoid obstacles, and how to ensure that multiple optimization objectives can be optimized simultaneously and reasonably is the research difficulty of this problem. This paper studies the multi-robot system in the automated logistics system. It analyzes the current multi-robot path planning technology and completes the overall design of a hierarchical path planning scheme, with the first layer being global path planning and the second layer being local path coordination. In the issue of global path planning, most algorithms have the disadvantages of slow convergence speed and insufficient convergence, and most only consider the single goal of path length, leading to unsmooth paths and poor safety performance.
In response to the problem of multi-load autonomous mobile robot cluster picking-and-delivery path planning, an improved multi-agent path planning algorithm based on conflict search is proposed. On the model level, replace KIVA robots with multi-load robots to establish a mathematical planning model aimed at minimizing picking-and-delivery time and invalid path ratio. On the algorithm level, first propose a multi-agent conflict resolution acceleration strategy based on priority rules; then, design an optimization algorithm for a single robot picking sequence based on dynamic programming; finally, design an enhanced A* search algorithm considering turning penalties to find the optimal path for robots. Experimental results show that the proposed model has significant advantages compared to the KIVA system; the proposed algorithm can effectively shorten picking-and-delivery time and reduce invalid path time.
